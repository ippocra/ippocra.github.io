FAQ

Questions before bringing AI into the company.

Essential answers about data, costs, hardware, channels, and how you work with ILAI.

Let's talk →See use cases

Is ILAI a cloud service?

It can be, if you choose it. ILAI runs on a dedicated machine that belongs to you: on-site (the default mode, where documents never leave) or in the cloud — a dedicated, private unit in an Italian data center, with Regolo-certified Zero Data Retention inference. See ILAI in the cloud →

What hardware does it need?

Usually a workstation with a dedicated GPU. The indicative investment is €3,000–€7,000 + VAT, depending on model, workload, and memory requirements.

Can we use a machine we already have?

Yes, if it has adequate resources. In that case we start with hardware verification, installation, and perimeter configuration.

What changes if I choose ILAI in the cloud?

You buy no hardware: you pay a monthly fee for a dedicated unit in an Italian data center (Seeweb), and your documents travel there — staying in Italy — with Zero Data Retention certified inference. Moving from the cloud to your own on-site machine is supported, when it makes sense. Cloud details →

How does it communicate with the team?

Through the channels you already use: Slack, Teams, WhatsApp, Telegram, Discord, email, or other integrable tools.

Where do we start?

With a concrete workflow: documents to read, information to retrieve, a repetitive task, or a report to produce periodically.

Is it the same product for everyone?

No. Every ILAI is configured around the company's context: documents, rules, channels, permissions, and processes vary case by case.
